# IO3: простая раскладка

Беспроводная IO3 на ZMK: две половины передают события по BLE отдельному
USB-донглу. Именно донгл обрабатывает раскладку. Контроллеры в сборке —
`nice_nano` (nRF52840); перед прошивкой сверяйте плату с `INFO_UF2.TXT` загрузчика.

## Три слоя

- **BASE**: QWERTY, обычные пробелы и Enter, отдельные Shift/Ctrl/Alt/Win.
- **NUM**: числа и символы; активен, пока удерживается клавиша NUM.
- **NAV**: стрелки и F1–F12; активен, пока удерживается клавиша NAV.

Двойных назначений по времени удержания, переключаемого игрового слоя и
команд очистки Bluetooth в раскладке нет. При одновременном удержании NUM и NAV
приоритет имеет NAV. Прозрачные назначения наследуются с активного нижнего слоя.

Буквы и символы ниже соответствуют US English в ОС. При стандартной русской
раскладке Windows физические коды `[`, `]`, `'`, `` ` `` дают х, ъ, э, ё.
Для них на NUM есть отдельные назначения без принудительного Shift.

## Основные клавиши

Левая основная часть:

```text
Tab    Q W E R T
Shift  A S D F G
Ctrl   Z X C V B
```

Правая основная часть:

```text
Y U I O P  Backspace
H J K L ;  Enter
N M , . /  Alt
```

Оба пробела сохранены в прежних логических позициях: физически подтверждены
средняя нижняя клавиша слева и крайняя правая нижняя клавиша справа.
Остальные нижние назначения: NUM и NAV слева, Esc и Win справа.
Их физический порядок следует проверить на конкретной PCB. В `.keymap`
нижние клавиши записаны между основными частями, а не отдельным четвёртым рядом.

## NUM

```text
Слева (после крайней служебной клавиши):
!  @  #  $  %
'  "  {  }  =
[  ]  \  `  ~

Справа:
*  7  8  9  -  Backspace
/  4  5  6  0  Enter
.  1  2  3  +  Alt
```

Скобки `()` получаются через Shift+9/0; `:`, `?`, `<`, `>`, `|` —
через Shift и соответствующий обычный знак. Результат зависит от языка ОС.

## NAV

F1–F5 расположены на левых Q–T, F6–F10 — на A–G, F11/F12 — на Z/X.
Стрелки справа: I — вверх, J — влево, K — вниз, L — вправо.
U/O — Home/End, P/`;` — Page Up/Page Down, Y — Insert.
Backspace становится Delete. Пробелы и основные модификаторы доступны и на NAV.

## Сборка

GitHub Actions запускается при push, pull request или вручную. Артефакт
`firmware` содержит отдельные UF2 для донгла, левой/правой половины и сброса
настроек. ZMK и reusable workflow закреплены на одном коммите
`cb786cd7d69f2a41f2968c2e5dd6a269d417286b`, доступном на момент прежней
успешной сборки 4 января 2026 года. Разводка GPIO и матрица оставлены прежними.

## Прошивка и проверка

1. Введите нужный контроллер в UF2-загрузчик двойным сбросом RST–GND.
   У nice!nano должен появиться диск `NICENANO`.
2. Прочитайте `INFO_UF2.TXT`, проверьте модель. Сохраните `CURRENT.UF2`,
   если загрузчик предоставляет его, как резервную копию до обновления.
3. Для изменения раскладки сначала обновите **донгл** файлом
   `IO3_dongle-nice_nano-zmk.uf2`. Он перезагрузится и будет называться
   **IO3 Simple**. Обычная прошивка сохраняет записанные настройки связи.
4. Проверьте ввод обеих половин, обычные пробелы, Enter, Ctrl/Shift,
   затем NUM и NAV. Включённые слои действуют до отпускания соответствующей клавиши.
5. Половины обновляйте соответствующими `IO3_left-...uf2` и
   `IO3_right-...uf2` только при необходимости общего обновления версии.
   Файлы половин и донгла не взаимозаменяемы.

`settings_reset` не нужен для обычной смены раскладки. Он удаляет сохранённые
настройки и используется отдельно, если требуется восстановить сопряжение.
Не обновляйте сам загрузчик для установки этой раскладки.
